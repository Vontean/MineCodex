# MineCodex Dashboard Design System

控制台帮助用户理解增强出现的位置、解决的问题与操作结果，再决定是否启用。
浏览器与官方 MCP App 共用 `index.html`、`styles.css`、`app.js` 和预览模块。
功能开关表示用户配置，实际状态来自控制服务；预览不读取、推断或修改实际状态。

## 页面与布局

一列居中的 1064px 内容区，无侧栏或营销分区。页面自上而下：品牌区、运行提示、功能演示、全部增强卡片、页尾。
顶部工具区在正常布局中右对齐，语言与当前明暗模式使用无常驻底色、无描边的纯图标按钮；40px热区。
浅色显示太阳，深色显示月亮；点击切换模式并同步图标，Tooltip说明当前与下一模式。

品牌区采用落地页式主视觉，让用户进入页面即理解 MineCodex 是什么：
- 标签胶囊在最上方：20px SVG 标识与“Codex 增强工具箱 · N 项”／“Enhancements for Codex · N”，N 取实际功能数，数据未到时只显示前半句。13px、999px 圆角、描边。
- 巨型像素字标为唯一主视觉：Silkscreen Bold，字号 clamp(40px, 12.8vw, 152px)，单行；1px 以上描边与按 em 等比的四级阶梯描边加一级深度阴影（0.016em 步进），颜色取本地黑白／灰品牌 token。
- 字标后方铺 32px 像素网格，线色为 `--border`，以椭圆径向遮罩向四周淡出；网格横跨视口宽度，内容面裁切横向溢出，不产生横向滚动。
- 像素网格为纯装饰，不接收指针事件；向上延伸到工具区时仍须让语言与主题按钮正常接收点击。
- Slogan 30px／600（窄屏22px），说明16px（窄屏15px）。文案为“让 Codex 更顺手。”与“按需开启交互增强，让日常使用更高效。”；英文分别为“Make Codex work better for you.”和“Enable the enhancements you need for a smoother daily workflow.”。
- 间距：标签到字标24px，字标到 Slogan 32px（窄屏24px），Slogan 到说明12px；品牌区下方56px（窄屏40px）。

运行提示仅显示真实服务异常与待重启事项。功能卡片按 API 顺序平级排列，
数量来自实际数据，不写死。卡片区上方有可见标题“全部增强”／“All enhancements”（20px／600），
右侧一行提示说明卡片与开关的分工：“点击卡片在上方查看演示，开关控制是否启用。”

网格默认三列，960px及以下两列，600px及以下单列；24px间距、24px内边距。
卡片最小高度216px，移动端204px；内容可增长，不截断用途与真实状态。
图标24px、2.1单位笔画；标题16px／600、描述14px／1.65、状态13px／1.5。
功能卡片使用细描边，无阴影。状态区位于底部，同一行卡片高度一致。卡片点击切换功能演示，只有开关改变功能配置。

页尾按关联分成两组：左侧版本与轻量更新检查；右侧数据迁移、诊断复制，使用次级描边胶囊按钮。
组内间隔12px，两组左右对齐，窄屏按组换行。更新只检查并提示，不自动安装。
重启只由已有显式按钮触发。错误保持可见，不用视觉降级掩盖真实异常。

## 独立视觉快照

Dashboard 的 `--canvas`、`--surface`、`--ink` 等变量由本地 CSS 定义确定值，
不读取原生 token，也不由宿主 `styles.variables` 注入数值。共享 Tooltip 所需的
`--mcx-*` 仅映射这些本地值。此例外不改变 Prompt 与其他注入页面的主题桥。
禁止跨 iframe 读取父窗口 DOM。没有宿主或样式桥时，本地主题仍完整。

下表数值取自 Codex **26.1007.21159** 原生 Renderer 根作用域的明暗计算值与官方 Prompt
卡片；记录的原生名称只是取证，不是运行时接口。

| --- | --- | --- |

| 次级底色 / 原生 `--color-surface-secondary` | `#f7f7f7` | `#141414` |
| 菜单与预览 / 原生 elevated-secondary | `#ffffff` | `#2d2d2d` |
| 主文字 / 原生 text-primary | `#0d0d0d` | `#ffffff` |

页面为均匀纯色，无渐变、窗口透明材质、地形或卡片硬质下沿投影。
品牌标题为明确例外：使用 MC 像素字轮廓，颜色为黑白灰品牌值。
字体仅用于品牌名称；Silkscreen 字体与 OFL 许可随资源保留，MCP 内置字体 data URL。
Prompt 卡片计算轮廓为 `superellipse(1)`，即普通圆角；不把原生 Tooltip 的
`superellipse(1.5)` 轮廓套到卡片。功能演示区使用细描边与圆角划分边界，不使用外框投影。
开关轨道36×21px，命中高度32px；选中用中性主文字色，状态仍用语义色。

本地快照不自动跟随原生改名或视觉更新。未来升级须先核对组件实际作用域，
再主动修改数值与本表。可用范围与自检证据不能替代真实操作验收。

## 语言与主题

语言按钮仅显示 Lucide `languages` 图标，Tooltip 告知当前语言；原生 auto popover
列出中文、English，`aria-pressed` 标明选择，Escape／空白点击关闭。外观只显示当前模式的太阳／月亮，Tooltip 和无障碍标签说明当前模式与切换动作，随语言变化。均支持键盘焦点。
手动明暗切换使用420ms圆形扩散，从明暗按钮中心覆盖当前内容视口；宿主／系统变化直接更新。
减少动态效果或不支持View Transition时直接切换。此动效仅在控制台自己的文档内执行。
Lucide ISC 许可在 `packages/ui/assets/lucide-LICENSE.txt`。

浏览器初始跟随系统，手动外观选择保存到本地。MCP App 初始跟随宿主，手动选择
仅作用于当前会话，下一次明确宿主主题事件重新跟随；尺寸增量事件不改主题。
宿主只发送 light／dark 信号。语言沿用本地保存与保存保护：功能请求未完成或重启
进行中不切换。浏览器重载本页获取一致文案；MCP 在当前上下文内更新文案与 API
语言，并同步数据迁移、预览与 Tooltip，避免 sandbox 重载丢失官方页面。

## 功能演示

`assets/feature-showcase.js` 管理演示区、播放器与卡片联动；演示区是页面常驻区块，不使用悬停浮层。
- **布局：** 24px 圆角、细描边、无阴影的大卡片，左侧 4:3 视频框（14px 圆角、次级底色、无描边、浅阴影 `0 4px 16px -6px #00000012`），右侧序号“03 / 13”、功能名（24px／600，窄屏20px）、出现位置／解决问题／操作与效果三项说明与控制按钮；下方通栏进度条。860px 及以下改为上下排列。
- **轮播：** 按卡片顺序播放各功能录屏，视频结束 600ms 后切到下一项，末项后回到第一项。没有视频的功能显示封面或“演示视频准备中”，自动轮播时停留6秒。进度条每段对应一个功能：已播放段 35% 不透明，当前段随视频时间填充，未播放段为空轨。
- **卡片联动：** 卡片覆盖一个无文字按钮，标签“在演示中查看 · 功能名”；点击切换到该功能，并将演示区滚动到距视口顶部 32px 的位置，600px 及以下留 24px；通过 `scroll-margin-top` 设置锚定留白。卡片不跟随轮播显示选中描边或 `aria-current`，键盘焦点提示仍保留。开关位于独立上层热区，点击开关不切换演示。
- **控制：** 上一个、暂停／播放、下一个三个 36px 圆形描边按钮，图标为 Lucide chevron-left／pause／play／chevron-right；Tooltip 与无障碍标签随语言变化。暂停只由用户切换；演示区离开视口（可见比例低于35%）或页面隐藏时暂停播放但保留用户选择，回来后继续。
- **减少动态效果：** 默认不自动播放，显示封面；用户点击播放后才开始。
- **资源：** 同时只存在一个播放器；切换时取消未完成的资源读取并释放旧视频源，pagehide 时释放。自动轮播期间说明区不使用 live region，避免读屏器反复播报。

## 内容与媒体接口

`assets/preview-content.js` 按稳定 feature ID 保存中英位置／问题／操作结果，
与卡片名称、实时状态分开。`assets/previews/manifest.json` 管素材关联。
示例格式：

```json
{
  "file-navigation": {
    "video": "file-navigation.webm",
    "poster": "file-navigation.webp",
    "version": "26.1007.21159"
  }
}
```

文件放在清单同目录，仅使用简单文件名。视频支持mp4／webm，封面支持png／jpg／webp。
素材必须是对应功能真实录制，演示框内等比contain，不裁切关键动作。录制规格：在[隔离窗口](../../packages/runtime-host/DEVELOPMENT.md#隔离验收)中使用浅色主题与英文界面；4:3、720×540、H.264 MP4（yuv420p），2× 速度，单段以 4–10 秒为宜；镜头只框住功能生效的区域并随操作平移，不对界面加压暗或模糊；以模拟光标呈现点击与悬停。个人内容按画面主角决定是否打码：历史标题等非主角文字加轻度模糊；以侧栏结构为主角的演示（如 Sidebar Focus）保持原样，避免影响观感。示例内容使用英文演示数据。封面取最能说明效果的一帧。录制工具与各功能剧本见 [scripts/record-previews](../../scripts/record-previews/README.md)。版本字段用于素材维护，不在演示区显示，也不表示当前会话兼容性。没有素材时演示框显示“演示视频准备中”，没有空播放器。
资源失败保留说明与可用封面。加载中显示低干扰文字。视频静音、内联播放，不显示原生播放器控件。
浏览器拒绝自动播放时切换为暂停状态，由用户点击播放继续。
切换素材或离开视口引起的正常播放中断不改变用户的播放选择；过期素材的播放结果不影响当前项。

浏览器在演示区首次选择功能时读取清单，只请求当前功能的媒体。MCP HTML 只内置清单，不内置
全部视频；通过 App.readServerResource 按需读取，读取结果按功能缓存，轮播回到同一项时不重复传输
`resource://minecodex/previews/{featureId}/{video|poster}`，得到本地data URL。
服务检查清单与扩展名，禁止越出资源目录。共享HTTP入口提供对应MIME及媒体CSP。
`apps/dashboard/assets` 已在npm包名单中，后续素材无需增加新的发布目录。
测试素材只留在忽略的验收目录／浏览器路由中，不作为产品演示或运行资源交付。

## 数据迁移与稳定性

沿用原生dialog的焦点与关闭行为，最大宽520px、padding24px。三个可迁移领域使用
各自业务预检与合并规则；GUI不直接读业务文件。导入导出仍为平级outline按钮，
busy状态禁止重复提交与关闭。说明复用共享Tooltip，仅从本地定义读取视觉值。
保存失败回退原值与焦点，并显示错误；刷新保留正在保存的功能。诊断只导出能力、
token与窗口证据，不导出安装路径、账号、会话内容或凭据。

验收涵盖明暗、中英、三／二／一列、轮播自动前进与卡片切换、键盘／触屏、reduce-motion、
无媒体／404／自动播放拒绝、宿主变量删除、真实隔离API保存与失败回退、数据迁移、
更新及官方sandbox。截图与DOM／API操作证据分别记录；真实录屏视觉与完整原生鼠标
链在素材与人工阶段单独验收，不用本地测试视频冒充已完成。

## 提示与反馈

品牌下方不放运行状态行；真实状态由各功能卡片与诊断提供。
重启提示仅在 pendingRestart 时出现，保留说明与业务操作；所有提示与错误反馈（重启、加载错误、Toast）不使用左侧色条，语义由图标、文字和状态色表达。重启按钮采用 999px 胶囊圆角。
卡片不显示“查看效果”文字，演示切换由无文字卡片按钮提供，支持鼠标、键盘与触屏。
