# Mermaid Diagrams

独立功能 `mermaid-diagrams` 在控制台提供“Mermaid 图表增强（实验性）”卡片，默认关闭。新配置与缺少此字段的旧配置均关闭；后续明确的用户选择保留。不继承 `markdown-reading` 开关，两者可分别开启。开关保存与应用沿用控制台现有重启流程。

关闭时保留 Codex 原生 Mermaid，无 QV 资源、iframe、下载能力或图表诊断加载。开启后只作用于 Markdown File Panel 的 Preview，不进入 Source、Pages 或聊天。运行时独立拥有 Preview 会话、主题映射、资源和自检；卸载移除自己的 CodeMirror 扩展并恢复原生图表，不释放阅读增强资源。

原生 Preview、CodeMirror API、Provider 与块操作组件的发现复用 Codex Adapter 的 `src/markdown/`，只消费已核对的接口。图表特有的保存协议由本功能的 `native.mjs` 维护，加载失败不影响阅读增强。Codex 26.1021.31345 使用原生导出的下载函数接入 `workspaceFiles.saveStream`，将 PNG Blob 直接交给原生保存流程；旧构建仍使用已核对的 `save-file` 请求。组件与下载函数同时支持本地导出及 import 绑定，不依赖压缩变量名。


闭合 Mermaid 围栏（源码不超过 50,000 字符）使用真正的 QV 模型、布局、绘制与样式。所有已收录的 QV 图型走同一入口；不支持的图型或显式自定义样式由 QV 自身保留 Mermaid 原生外观。不改写源文件。不闭合或过长的围栏保留宿主行为。

`vendor/qv/source` 是 QuickerVisulize 的源码快照，来源 commit 与逐文件 SHA-256 见 `vendor/qv/provenance.json`。`scripts/build-qv-mermaid.mjs` 从该快照组装资源，保留模型、布局、几何、绘制、CSS，以及 QV 原版进场、重新进入视口重播、分组切换、visibilitychange 与减少动态效果逻辑；默认不再采用静态转换。节点／连线进场时长与空间顺序由各图型原版实现拥有，不维护第二套动画配方。hover 与普通尺寸变化是否重播沿用 QV 原版规则；减少动态效果关闭进场／重播，已有轻微 hover 状态过渡与进场分开记录。

`staticQvScript` 仅用于显式 motion=false 的构建对照，仍正确识别裸 matchMedia 和 window.matchMedia；运行包使用默认动效构建。提示删减与原生视口桥在两种构建中都保留，不因恢复动画而回退节点组、提示与放大行为。

阅读交互采用明确的构建适配，不修改 vendor 快照：架构图删除“节点组”开关和分组下钻，始终完整展示所有节点，保留源码分组边框、名称和关系高亮。流程图默认 `navigation='expanded'`，完整展示所有节点；其“节点组” checkbox 开关默认关闭，开启后沿用 QV 分组浏览。时序图提示、类图关系提示、实体关系图提示、状态图详情提示、块图节点与连线提示均取消，保留 hover／focus 的关系高亮与键盘可达性。甘特图任务与日期等补充信息提示保留；C4 图提示及架构节点详情也取消，保留关联高亮；其他图型的有效数据提示保留。饼图继续使用原版直接标签／底部图例的响应式选择，图形与标签必须实际可见，不能仅以 enhanced 状态判定成功。

依赖固定为 Mermaid 11.12.0、ELK 0.10.0、D3 7.9.0、d3-sankey 0.12.3、Lucide 0.468.0；它们是构建依赖，打包结果随 feature 发布，运行时不访问 CDN。`npm run build:mermaid` 重建 `assets/qv-template.json`、`assets/qv-dependencies.js` 和依赖许可通知。更新快照或依赖时同步 provenance／许可并重新验证。

`src/mermaid/frame.mjs` 拥有独立文档与主题／高度／显示模式消息桥；`src/adapters/codex/mermaid.mjs` 以最高优先级 CodeMirror StateField 替换闭合图表块，避免原生组件重复绘制。`mermaid-viewer.mjs` 复用原生 Actions、CopyButton、Tooltip、扩展图标和 TablePreview。独立 Runtime 按 Preview 安装，`mermaid-diagrams-renderer` 依据当前挂载图的 ready 状态报告；仅挂载容器不算渲染成功。

依赖与渲染脚本按文档共享交付地址：`createQvResources` 为每份脚本建立一次 blob URL 并由引用计数持有，图表帧只按 URL 取用，不再逐帧复制源码、重复建 Blob，并允许浏览器复用编译缓存；最后一个预览释放时撤销 URL。`globalThis.__mcxQvScripts` 是这份共享的唯一所有者，以脚本源码为键，内容变化不会复用旧地址；子页只接受 blob: 脚本地址，引导消息仍核对发送窗口与随机 token。

图表使用 `srcdoc` iframe，sandbox 为 `allow-scripts allow-same-origin`；这是 CSS、Mermaid 全局对象与生命周期隔离，不是对不可信脚本的安全边界。仅运行固定的打包代码，源码作为配置数据传入，Mermaid 使用 strict 安全级别；消息核对发送窗口与随机 token。加载遵循 Runtime Host 既有 CDP CSP bypass 契约，同源子页用于保持该契约，不使用被宿主拦截的 data: 导航。iframe 内 CSP 禁止网络请求。

主题与字体从 Preview 的实际 token 映射到 QV 变量，不覆盖 QV 图表 CSS；QV 系列色使用快照所需变量和默认色。相同源码、宽度、主题与字体下验证与 QV 静止态的节点尺寸、位置、形状与连线路径一致；不同宿主主题的颜色不能宣称逐像素相同。

整图换行／方向调整阈值取 Preview 的 `--mcx-reading-width` 最大正文宽度：用临时测量元素解析实际 CSS 长度；阅读增强关闭时直接使用同一原生 token 公式，将结果作为 `readingWidth` 传入 QV 配置；当前隔离实例为 736px，不硬编码该值，也不随窄面板或放大画布宽度改变阈值。仅调整已有自适应布局：流程图宽度超过阈值时使用原有蛇形分行算法，候选布局优先避免超出该宽度；横向类图超过阈值时比较纵向布局，仅接受更窄结果；分组内横向图方向比较也使用同一阈值。移除旧 2400px／16 节点／长宽比门槛，保留分组边界和显式连接面限制。不调整节点文字、时序参与者、时间轴或看板等专有宽度规则；无法容纳的节点或拓扑仍允许横向滚动。放大视图复用这份排版，90% fit 和缩放只改变显示比例。

内联图保持文字大小，超宽时由 QV 图块横向滚动。图块上方预留 44px 操作栏，复制返回 Mermaid 源码；放大按钮在图就绪后启用。加载阶段显示 QV skill 的共享网点动效：`vendor/qv/source/chart-loading.html` 原样快照，由构建器提取绘制逻辑生成 `src/mermaid/loading.mjs` 与 `assets/qv-loading.css`。保留原版点阵密度、双明暗场、30fps、1.75s 透明度呼吸与渐变遮罩；加载期间预留 280px，不设置最短展示时间。实际图表 ready 后立即移除网点，失败／30 秒超时／虚拟卸载／关闭预览也停止动画、取消待执行的动画帧、断开尺寸观察与事件监听。页面不可见时暂停；prefers-reduced-motion 显示静态点阵。网点只属于加载阶段，图表 ready 后接续各图型的 QV 进场动效。加载失败或 30 秒没有 ready 回报时显示失败说明，不永久留空，不报告成功。

放大复用当前 Codex 原生 Mermaid 的 ImagePreview 外壳（本 Adapter 沿用 TablePreview 名称）：`imageSurface='card'`，窗口内 `100dvh` 高度，无固定像素上限；右上关闭、底部缩放操作、圆角卡片与卡片内边距沿用原生。2026-10-14，Codex 26.1007.30912 原生 Mermaid 组件在隔离实例临时挂载与源码交叉核对：1803×1122 视口中外壳顶48／底32／左右32px，卡片1739×978，内边距16px，可用区域1707×946；这些是该尺寸下的实测，不硬编码成高度预算。窄窗口遵循原生响应式 gutter。

用户视觉验收要求白色卡片缩小并与关闭按钮分开：仅在本图表查看器的原生外壳增加顶部64px、底部48px、左右clamp(16px, 4vw, 48px)留白；不改变原生按钮、胶囊、图标或其他查看器。原因是原生此分支48px顶留白与关闭按钮52px下沿存在4px相交。1803×1122视口下卡片由1739×978缩至1707×946（左48、顶64），与关闭按钮下沿保持12px间距；这是用户选择的局部布局分支，不宣称与未经调整的原生卡片尺寸完全一致。

取消 Actual size / Fit to view 两档切换。直接使用原生查看器的 `zoomableContent` 与 `showZoomControls=true`：图表等比适配到可用画幅的 90%（宽或高其中一边达到 90%），以这个适配尺寸作为 natural size 和 100% 基准，窗口尺寸变化时重新计算。小图也按此基准放大。原生拥有比例状态、缩放范围、底部胶囊、缩放图标和关闭按钮，没有自制按钮或胶囊配方。iframe 保持固定自然尺寸，通过变换跟随原生缩放，图表居中且不因缩放重新排版。

`FrameView` 通过 `Element.moveBefore` 移动同一个 iframe，固定其自然宽高；跟随原生内容容器的缩放比例，仅更新 iframe 的 CSS transform，手势期间不重新解析或重排图表。`src/mermaid/viewport.mjs` 替换 QV 的视口控制器，只提供完整场景、iframe 输入转发与正文恢复；原生回退、饼图／雷达独立模板也在 ready 后接入。饼图的标签和图例与图形一起缩放。进入查看器后不启用 QV 的另一套 fit／hug 几何，缩放比例只由原生查看器拥有。

下载入口放在正文“复制”与“放大”之间；放大窗口使用原生 `showDownload`／`onDownload`，位于关闭按钮左侧。两处共用 PNG 导出及 Codex `save-file` 接口。该接口的原生实现以 `dialog.showSaveDialog({defaultPath})` 打开系统保存窗口；Preview Adapter 从当前 runtime 用户的 home 生成 Downloads 下的建议文件路径，用户确认保存或取消。不通过浏览器 anchor download，不静默覆盖文件，不加入 Runtime Host 私有写文件接口。原生导出名按当前公开导出与调用语义发现，失败显式停用 Adapter。

下载按放大查看器的可用画布尺寸导出，而非图表自然尺寸或当前缩放截屏；图表复用 Preview 排版、等比居中，宽或高占画布90%，不含操作按钮、提示和分组开关。窗口内下载直接读取真实画布尺寸；正文下载临时挂载不可见的原生 inline ImagePreview，复用同一外壳约束测量尺寸后立即移除，避免维护第二套画布尺寸公式。PNG 每边使用2倍像素；原始图像按需要提高采样比例，避免小图先低分辨率导出再放大。使用当前图表主题与分组范围，当前显示缩放不影响下载结果。

`src/mermaid/export.mjs` 只在离屏副本上展开完整 scene，冻结 SVG 子节点的计算样式与单行文字，移除进场 reveal mask／sankey reveal clip，保留语义渐变 mask。DOM 转图片采用 MIT `html-to-image@1.11.13`，打包为约13KB的离线 `qv-export.js`，点击时在当前图表帧内加载；共享交付 URL，导出 API 不跨帧共享，避免长期持有已卸载的图表 realm。有限 Web Animations 等待结束，雷达 rAF 几何变化等待稳定；导出副本、合成图像 URL 与测量视图完成或失败时释放。重复点击不重复发起保存；失败可重试，取消系统窗口不报告错误。

滚轮与触控板缩放手势从子页转给原生查看器，保留指针锚点。鼠标拖拽以5px阈值区分点击，通过原生滚动容器平移；拖动后的 click 不触发节点／分组。方向键可平移；其他快捷键沿用原生查看器，未宣称图内转发支持全部宿主快捷键。普通点击、hover、分组状态与主题继续保留。原生 Escape 与关闭恢复正文位置和焦点，下次打开由原生重新适配全貌。分组或容器尺寸变化按原生自然尺寸／显式缩放状态处理，不维护第二套比例状态。

子页输入回报核对来源窗口与 token，桥与尺寸观察器随 FrameView 释放。关闭后 iframe 放回正文，清除外层缩放与自然宽度，恢复内联高度、横向位置与触发按钮焦点；不重建图或 SVG 副本。宿主不支持 moveBefore 时明确报告 Adapter 不可用。图表帧、消息监听、超时和 React root 归同一挂载实例释放，共享脚本 URL 由资源引用计数释放；Source、禁用与虚拟卸载均清理。

共享 URL 的多图加载收益已在独立浏览器同条件 A/B 和真实宿主中验证。虚拟滚动计时必须按图表身份与挂载次数记录；包含不同数量重挂载的逐帧耗时求和不能当作整页等待时间。资源体积、JS 堆与进程 RSS 分别记录，具体样例测量不作为固定性能预算。

原生契约依据：Codex 26.1007.30912 隔离实例，真实 Runtime Host 接入。18 种已收录图型在同一文档内逐项加载，均已进入对应 QV renderer 且无回退、无失败提示；五节点 flowchart 的节点尺寸／位置／形状与四条连线路径与源 QV 静止态逐值一致。放大外壳／Escape／焦点恢复、分组下钻及其在全屏前后的作用域保留、Source／Preview 切换释放并重新挂载、深色与窄宽度渲染均已检查。非 Markdown 文件关闭预览后共享脚本 URL 被回收，18 图挂载不增加 URL 数量。更长的真实文档与全部图型的语法覆盖仍需相应样例验收，不能由上述样例推断全面通过。自动检查与用户视觉确认分别记录。

### 内存与测量边界

每个挂载图表拥有独立 iframe，依赖和渲染脚本各自求值；共享的是交付地址，不是运行实例。CodeMirror 虚拟卸载与 Preview 清理移除图表帧、控件、监听和超时；最后一个 Preview 释放共享脚本 URL。对象回收和进程归还内存不保证同步发生。

JS 堆、外部存储与进程 RSS 是不同口径。纯依赖加载消融不包含布局峰值；页面内存差值不能全部归因于图表，更不能据此断言成本主要来自某个库或 Blink。长时残留与责任归属需要无探针强引用的独立 profile、同条件对照及保留路径证据。测量器应取消自己的轮询并释放状态，不用普通 Map 长期持有 DOM 节点。

当前没有实施按图型拆依赖或共享计算环境。它们的收益与可行性需分别验证，不因包体积或未经归属的残留数据直接排除；方案必须保留图型语义、主题、分组、提示、原生回退和现有交互。
