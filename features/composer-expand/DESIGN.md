# 长指令展开编辑

入口、Expand/Collapse 图标与控件尺寸直接使用 Chat 原生组件的 `ghostSecondary` / `iconCircle` 分支，位于输入框主体右上角，间距沿用原生 spacing × 2.5。悬浮提示与无障碍名称跟随宿主语言。

展开使用已有原生输入框材质、圆角、排版、附件区与可滚动编辑区。高度消费原生 `--composer-expanded-height`，不新增全屏遮罩、独立窗口或复制草稿。Work 与 Codex 的会话页保留底边锚定。Codex 首页沿用底边锚定，展开时覆盖共享布局的居中规则，仅向上增长。Work 首页长文本处于收起状态时，标题与输入框作为一个整体居中，避免原生比例分区让新增高度全部向下堆积；短文本还原原生首页布局。展开时使用原生大编辑区布局。
