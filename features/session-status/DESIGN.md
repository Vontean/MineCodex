# Session Status 设计约定

通用视觉、材质、按钮、Tooltip 与原生 sidebar 层级遵循根 [DESIGN.md](../../DESIGN.md)。本文件只记录功能特有组件、布局、数据语义与通用组件选型。

## 意图

状态行紧随 Codex 原生输入框，帮助用户在长任务中快速判断回合、模型步骤、输出速度和 token 用量。视觉上作为输入框的附属信息，不争夺发送按钮与模型选择器的层级。

## Token 与布局

状态栏实例跟随可见正式会话的原生 Composer root，不跟随 contenteditable 编辑节点。发送时编辑区暂时不可交互或重建，同一外壳、同一会话的状态栏继续显示并保留展开选择和统计；不以延时隐藏掩盖变化。真正切换会话时清除旧统计，进入 home、隐藏外壳或迁入浮动输入框时移除实例。宿主读取身份与 Renderer 使用同一个 `composerSurface` 契约。

| 角色 | Codex token | 用途 |
| --- | --- | --- |
| 次要文字 | `--color-text-tertiary` | 状态行文字与分隔符 |
| 主要文字 | `--color-text-primary` | 弹层标题和数值 |
| 分类进度 | Codex `--app-block-accent-purple`、`--app-block-accent-blue`、`--app-block-accent-green`，以及 `--color-token-border-default` | 各弹层的分类比例与未分类段 |

状态行和输入框共用内容宽度，单行高度为 24px，顶部留 2px 内边距；每个状态按钮高 22px，内边距为上下 3px、左右 6px。按钮之间 gap 为 4px，两组可见内容间距为 16px（6 + 4 + 6）；按钮内图标与文字 gap 为 6px。状态行展开且可见时，在包含它的原生 `[data-thread-scroll-footer="true"]` 容器上将 `--thread-composer-bottom-inset` 设为 4px；默认主聊天底部 padding 从 16px 收为 4px，收起、隐藏或卸载后自动恢复。原生 panel 的 `pb-3` 与 compact 分支不消费该变量，保留其独立留白。展开的状态行使用 -4px 顶部外边距，将输入框下方原生 8px gap 的实际距离收为4px，收起时恢复。宽度不足时自然换行，不覆盖输入框或悬浮控件。统计图标采用 Lucide Gauge，用量图标采用 Phosphor Database 单路径版本，两者以 14px 绘制；上下文使用与 Codex 原生相同参数的 12px 百分环。弹层由按钮锚定，键盘可聚焦，Escape 和点击外部关闭。遵守系统减少动态效果设置，不添加持续动画。

挂载依据：2026-10-02，Codex 26.930.21537 的主聊天实测 DOM 与 `thread-scroll-layout` / `app-primary` 源码。状态行仍作为 `[data-codex-composer-root]` 的紧邻后续节点；中间的 `display:contents` 包装不改变它与输入框在外层 flex 中的顺序和宽度。折叠入口放在 reasoning 控件最接近 `items-center` 控制组的包装节点之前；原生 Context 环仍为带 `aria-label`、`role=img` 的 span，包含 SVG circle。新版默认 footer 使用 `pb-(--thread-composer-bottom-inset)`，不再匹配旧 `.pb-4` 规则。panel/compact 分支来自源码，未据此宣称侧边聊天的手动验收已完成。

状态行以当前输入框所在的会话为准，不依赖侧栏中可能因项目折叠而卸载的 Thread 行。新聊天没有会话 ID 时隐藏旧数据；首条消息建立会话后默认展开详细状态行；若用户曾收起，则沿用其选择。尚未取得的指标用 `—` 占位，不等待日志或 Token 用量；切换会话时立即清空旧数值，详情展开状态保持不变。

## 数据呈现

界面文案跟随 Codex 的 `html[lang]`：中文语言使用简体中文，其他语言使用英文；运行中切换语言时同步更新状态行和已打开的明细浮窗。MineCodex Web 使用同样的中英文规则提供本功能开关。

状态栏与详情浮窗共用同一 TPS：取最近 5 个有有效计时样本且可确定回合归属的回合，将输出 Token 总数除以有效观测总时长，以 `N tok/s` 呈现。同一回合的多次模型响应合并，无有效数据的回合跳过；计时只接受有限正时长，完整的长响应不按固定时长上限排除。不足 5 轮时使用已有轮数，当前进行中的回合产生有效样本后即参与。分母仅扣除完整落在同一响应计时范围内、且不与已观测模型输出重叠的工具区间（含迟到事件，重叠区间仅扣一次）；跨响应运行或与生成并行的后台工具不扣时，模型输出缺少结束时间时保守保留该样本的观测时长，不将其视为实时解码速度；缺少有效计时样本时显示 `—`。累计 token 与缓存比例来自 Codex 用量记录。上下文使用原生 Codex 桌面版的口径：最近请求 `last.totalTokens / modelContextWindow`，直接订阅原生会话的 `latestTokenUsageInfo`（`thread/tokenUsage/updated` 更新），压缩后与原生同步刷新，不依赖日志轮询；原生数据不可用时显示占位；状态栏显示百分环和数字，弹层显示用量、窗口容量和压缩次数。二级浮窗的 token 数按十进制换算为 K/M，省略 `tok` 后缀；TPS 仍保留 `tok/s`。日志可见历史只列有数据的指令、消息、工具交互三个短标签，估算值以 `~` 开头；工具结果同时接受字符串与内容数组，压缩后的 replacement_history 采用同一文本解析。6px 进度条使用 Codex 图标选择器的紫、蓝、绿配色，标签圆点保持同色；当前页面未暴露对应变量时使用 Codex 亮／暗主题原值。剩余的原生占用以浅灰表示；若估算合计超过原生占用，按比例缩放彩色段，让进度条终点始终对应原生总占用。不显示无法取得的工具定义，也不放解释性长文案。

上下文弹层按视觉归属排列：进度条下紧接三个可见历史分段，不加分段副标题；分隔线之后列原生占用合计、窗口容量和压缩次数。合计取原生最近请求用量，不是三个估算分段的求和。

会话统计浮窗只显示回合、步骤、首字延迟和 TPS。Token 用量浮窗以 Total 为主项，紧接比例条和输出（紫）、其他输入（蓝）、缓存输入（绿）三项，顺序与上下文弹层一致；分隔线后才显示缓存命中率。其他输入为总输入减缓存输入，包含缓存写入。三项使用同一分母。

TPS 标签后放置 12px Lucide info 图标，继承标签颜色，间距 6px。悬浮或键盘聚焦时使用共享 MineCodex tooltip，说明 GPT 等模型未公开完整思考过程及逐 Token 生成时间，此处为体感响应速度参考值，不代表真实 Token 生成速度；中英文随界面语言切换。Tooltip 层级高于详情浮窗。

### 折叠入口
- 首次安装默认展开；用户收起后在模型选择左侧显示 12px context 环，24px 热区；原生 context 环开启时隐藏原生重复入口，卸载时恢复。
- Tooltip 沿用原生 context 内容：上下文窗口、使用/剩余比例、已用/容量（k tokens）；样式遵循通用 Tooltip。
- 点击环展开输入框下方详情，右侧 chevron-up 收起。原生布局一次切换到目标状态，测量切换前后的位置，仅用 transform 衔接输入框与模型控件；状态行入场配合4px位移与透明度过渡；中途反向按当前位移衔接。展开220ms、收起160ms，曲线 `cubic-bezier(0.23,1,0.32,1)`。反向操作从当前可见位置和透明度继续，取消旧动画；退出内容临时脱离布局，结束后恢复并 display:none，不保留父级 gap。reduced-motion 立即切换，收起内容不参与键盘焦点。展开状态跨会话、主聊天和 side chat 共享并持久保存，展开时隐藏输入框内的 context 环；每个输入框订阅自己的会话上下文和统计。
- Cache 按原始 cachedInputTokens / inputTokens 计算：大于99%显示一位小数，其余取整数，状态栏和详情共用格式。

输入框实例仅绑定可见的 thread composer。全屏标签页中的隐藏聊天、浮动 Quick Chat（含 right-panel composer overlay）、inert 区域不注入；原生移动输入框或切换可见性时销毁实例并取消订阅，返回聊天后重建。

明细采用通用 Popover，保持本功能的定位、尺寸及内容层级。当前通过 UI 组件库的 `config.ui.surface(panel, "popover")` 选择原生 Popover；功能继续拥有定位、尺寸与内容。
