# 任务切换：会话通知

通用视觉、材质、按钮、Tooltip 与原生 sidebar 层级遵循根 [DESIGN.md](../../DESIGN.md)。本文件记录通知条的触发、布局和状态规则。

## 触发与原生边界

会话侧栏不可见时，左上方自动显示通知堆栈，包括 Home 折叠状态，以及 Space、Projects 等没有会话侧栏的页面。判断真实会话导航内容的可见性，不把“侧栏展开偏好”当作当前页面具有会话侧栏的证据。Home 为当前导航且侧栏展开时，按原生 trigger 的 aria-expanded 立即隐藏通知，不等待会话列表挂载、布局或每秒刷新；原生状态 CSS 约束同步隐藏卡片、装饰和展开按钮，Adapter 同时检查全部可见会话列表。Home 临时侧栏或其他原生侧栏 peeking 展开期间隐藏通知；离开后恢复，原生悬浮侧栏保持可进入、可点击。

不创建额外入口，不改 Chat 标题的属性、热区和窗口拖拽行为，不替换 Sidebar.left 图标，也不修改 Home 原生蓝点。不点击 Activity、不切换原生筛选或展开偏好。旧入口在 Runtime Host 替换插件时由旧实例 cleanup 恢复。

## 通知条

堆栈以 Navbar 右侧8px、原生标题栏下沿8px为左上角原点；无标题栏内容时取 Navbar 顶缘。位置不依赖可点击的会话标题。宽320px，窄窗口缩小，右侧／底部保留12px。每条是独立的共享 opaque Popover，圆角16px，间距8px；没有列表标题、整块菜单底板或页面遮罩。堆栈位于页面和常驻二级侧栏之上、原生菜单和模态浮层之下（当前角色实现层级45）；原生侧栏 peeking 时暂停呈现。空白区域不拦截点击，溢出可滚动。默认仅显示前三条通知；超过三条时，第三条下方露出两层逐级缩进的卡片边缘，并显示“X more notifications”按钮，X 为总数减三。点击后展开全部，使用窗口剩余高度；只有展开内容超出该高度时才启用底部半条左右的渐隐，不再显示遮挡数量文字。滚动到底部解除渐隐。展开状态仅限当前页面；原生内存路由 pathname 变化（包括会话跳转）后恢复三条，并回到堆栈顶部。同页通知刷新、滚动及临时侧栏隐藏不重置。跨页收拢使用320ms缓出高度过渡，多余卡片淡出，层叠与按钮跟随收拢显现；尊重 reduced-motion。通知清空、账号切换或插件重载也重置。

条目保持现有信息结构：13px/18px标题、可用时的12px/16px原生回答摘要（最多两行，超出截断；短摘要不强占两行）、11px/16px项目名与12px原生项目图标。远程图标紧随标题；状态显示需要回复／等待批准标签、相对时间。未读且已结束的条目在时间右侧显示蓝点。内容 padding 四周统一使用功能 spacing token `--mcx-notification-padding:14px`，行间4px。状态文字和无障碍标签随宿主语言，用户标题和摘要不翻译。

新条目与堆栈推移采用320ms ease-out（cubic-bezier(.22,1,.36,1)），从当前视觉位置接续被打断的移动；状态解除以180ms淡出并收拢空位。内容更新保留卡片和点击目标，采用180ms淡入，不重播整卡入场；倒计时只更新标签内的数字与进度，不重建标签。尊重 reduced-motion。键盘可聚焦并点击条目；右上角外沿关闭按钮在 hover／focus 时显示，关闭仅影响本窗口通知，不标记原生已读。

## 状态与生命周期

- 范围沿用原有 Codex 会话类别：需要回复、等待批准、已结束且未读；排除单纯 Loading 和没有这些状态的最近访问会话。
- 每个 Thread key 只保留一条；按状态事件发生顺序倒序，而非按状态优先级。首次载入按原生消息时间排序。
- 需要回复／批准与已结束未读之间的变化产生新事件；未读状态下消息时间变化也产生新事件。Loading 不产生通知；普通摘要刷新和重绘不改变顺序。
- 当前可见会话、已解决／已读或重新进入 Loading、从原生目录移除的会话自动移除。身份消失不沿用 sidebar 残留选中项。
- 通知不自动超时消失；可点击跳转、关闭单条，或等原生状态消除。关闭后同一事件不重复弹出，新事件可以再次提醒。
- 侧栏显示时暂停呈现，保持状态跟踪；重新折叠时显示仍有效的通知。账号变化清空本窗口关闭记录。
- Needs input 的倒计时读取原生自动处理请求：pendingRequest 的 userInputRequestId 必须匹配 resolution 的 requestId，且 resolutionState.status 为 scheduled。标签同步剩余秒数及进度，暂停或延期跟随原生数据。归零不自行推断 Working；原生 attention 清除并恢复 Loading 后才退出。当前安装版本 Awaiting approval 没有倒计时契约，不伪造计时或自动批准。
- 不持久化通知正文，不发送消息、不执行批准操作。订阅原生 store 变化，并保留每秒刷新以更新相对时间与倒计时；DOM／窗口布局变化也触发刷新；不为通知发送网络请求。首次连接读取安装包 JS 以解析原生角色。

## 数据适配与验证边界

Codex 26.930.21537，2026-10-03：隔离 Renderer 确认侧栏只挂载7条，而原生 `allSidebarThreadKeys` 目录含72条。Adapter 从 Navbar 当前 React scope 读取原生目录、需要回复／批准、工作与未读 selector，并复用原生会话导航函数。不会因项目折叠或 Space 页面隐藏 Home 列表而只剩可见条目。项目归属来自原生项目目录；标题使用原生实时标题 selector。摘要沿用 View Activity 的数据与转换契约：从原生 turns selector 倒序查找最近的 agentMessage，调用同一原生文本转换函数，不再从侧栏行 DOM 读取。原生 scope.watch 订阅目录、项目、标题、状态、未读及回复数据，更新时刷新原卡片；摘要晚到不改变通知事件、排序或关闭记录。未读／待输入／待批准时机仍由原生状态决定，不为了等待摘要而延迟提醒；原生没有可用回复时不编造文字。项目图标仍在相应原生行已挂载时读取。

压缩符号及导出名通过语义调用关系动态解析；文件名哈希不作为契约。缺失模块／scope／状态契约时隐藏通知并通过 `nativeCapabilities()` 报告，不使用旧账号或旧会话快照假装成功。尚未创建的任务占位不显示，原有非 Codex 的 ChatGPT 会话不因本次改版新增覆盖范围。

验证覆盖队列去重、状态新旧、已读／当前／移除、关闭与再次提醒、源码序列化、原生角色契约、侧栏可见性和卸载。真实等待批准／输入事件需要实际发生才能完成端到端验收；受控样例只证明呈现与交互，不冒充真实通知到达。

- 等待批准沿用原生绿色标签，通过共享主题映射读取 chart-green；远程任务保留标题旁的原生远程设备图标。
- 关闭按钮使用原生 SVG 在圆形容器内居中；常态与 hover 均保留不透明底色，避免露出通知边框。
