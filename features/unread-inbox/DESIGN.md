# 任务切换

通用视觉、材质、按钮、Tooltip 与原生 sidebar 层级遵循根 [DESIGN.md](../../DESIGN.md)。本文件只记录功能特有组件、布局、数据语义与通用组件选型。

仅在线程侧栏收起时显示入口；展开时移除入口并关闭浮层。入口随 Codex 标题栏布局切换：
- 普通／分栏：在主 Chat 标题前显示原生 list-bullet 图标；整段标题可点击。
- 全宽标签页：在 Chat 标签页前注入独立的任务图标按钮。
- 移除扩展铃铛，注入入口存在时，用原生完整 SVG 显示无蓝点的 Sidebar 图标；保留 React 原节点，卸载或展开侧栏时移除替代图标并恢复原节点。
- 悬停入口150ms展开；鼠标离开入口与浮层250ms后关闭，跨越8px间隙进入浮层会取消关闭。点击入口确保打开；点击外部、Escape 关闭。Enter、空格、ArrowDown 可打开。

入口克隆原生 Chat 标题控件，通用反馈遵循根规范。入口仅 hover 显示背景，不保持选中底色。标题区域 no-drag，其他标题栏区域保留窗口拖拽。

浮层宽320px（窄窗口缩小），最大高440px（约5条，受视口高度限制）；选择通用 Popover，功能圆角16px，外层上下 padding 6px、左右0；滚动容器左右 padding 6px，使滚动条靠近浮层边缘。位置对齐标题触发区域左侧、底缘下方8px，并受窗口边界约束。

列表集合为等待回复／批准、工作中、最近1小时打开过、未读的会话，按 Thread ID 去重。按需要回复、等待批准、未读、执行中、空闲排序，同级按消息时间倒序；排除当前会话。原生流式摘要变化时更新观测消息时间，不因菜单重绘更新时间。最近访问记录限定当前窗口运行期间。每条显示：
1. 单行标题（13px/18px），远程标识紧随标题且不显示主机名；右侧状态优先级为待确认标签、原生 loading、相对时间。背景仅 hover 时显示。
2. 单行省略的 AI 回答摘要（12px/16px）。
3. 所属 Project 原生图标（12px）与名称（若有），11px/16px 弱化文字，不合并分组。条目 padding 10px 12px，行间 gap 4px，圆角10px。

时间使用原生 hover card 的 recencyAt，缺失时 updatedAt；每30秒刷新。工作状态读取原生 statusState.type=loading。缓存会话数据与原生导航回调，复用导航和已读更新，不缓存 DOM 行，不发送消息。

打开时临时启用 Activity 以取得完整列表，关闭或卸载时恢复原先模式。只读取原生数据，预览不标记已读。界面及无障碍文案适配中英文。

入口只显示任务图标，不显示数量。浮层标题为 Recent activity／最近活动，反映工作中、未读与最近访问的集合；不将最近访问误称为待处理。浮层无页面遮罩，点击外部关闭，Escape 关闭并返回入口焦点。

标题固定、条目容器独立滚动；上下保留6px内边距；条目内容左右保留6px，滚动条不受外层横向内边距挤压。

点击后先同步显示浮层与可用数据，首帧绘制后再切换原生 Activity 补全条目；关闭或卸载会取消尚未开始的切换。

消息刷新时保留列表滚动位置与条目键盘焦点。当前身份消失时清除选中状态，最近访问缓存按一小时过期。

待确认状态读取原生行的 `statusPill.label.props.id=codex.localTaskRow.needsInput` 或 `chips[].id=awaiting-approval`，不根据摘要推断。Needs input／需要回复沿用原生 chart-blue 15% 背景，Awaiting approval／等待批准沿用 chart-green 20% 背景与圆角胶囊；适配紧凑行使用12px/16px文字。点击条目仍仅导航，不执行批准或原生 Snooze 动作。

滚动条与原生 overflow 容器一致：thin，静止使用 `--color-border`，hover/active 使用 `--color-border-strong`，轨道透明；不使用全局较深的 `--scrollbar-color`。

入口提醒点：排除当前会话后，有需要回复或批准时为红色 `#FF3B30`，否则存在未读为原生蓝色 `--blue-400`；只有执行中或空闲则无点。点直径6px。无其他命中会话时不打开浮层，包括仅当前会话命中的情况。原生侧栏图标与 MineCodex 提醒随注入／卸载同步恢复。

浮层标题颜色与原生 Sidebar 类别标题一致，使用 `--color-text-tertiary`。

当前通过共享 `config.ui.surface` 接入；该接口尚未区分原生组件分支，后续迁移显式选择 Popover 材质。功能继续拥有定位、尺寸与列表内容。
