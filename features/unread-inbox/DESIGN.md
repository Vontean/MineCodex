# 任务切换

仅在线程侧栏收起时显示入口；展开时移除入口并关闭浮层与遮罩。入口随 Codex 标题栏布局切换：
- 普通／分栏：在主 Chat 标题前显示原生 list-bullet 图标；整段标题可点击。
- 全宽标签页：在 Chat 标签页前注入独立的任务图标按钮。
- 移除扩展铃铛，不修改原生 Sidebar 图标及通知蓝点。
- 点击打开或关闭；点击外部、Escape 关闭。Enter、空格、ArrowDown 可打开。移开鼠标不关闭。

样式使用原生字体、text-secondary、radius-lg、primary-ghost-hover 与 ring token。入口仅 hover 显示背景，不保持选中底色。标题区域 no-drag，其他标题栏区域保留窗口拖拽。

浮层宽320px（窄窗口缩小），最大高660px（约6条，受视口高度限制）；沿用 dropdown 背景、border、radius-2xl、shadow-xl-spread。位置对齐标题触发区域左侧、底缘下方8px，并受窗口边界约束。

列表集合为工作中、最近1小时打开过、未读的会话，按 Thread ID 去重。统一按消息时间倒序，当前会话仅标记选中，不置顶。原生流式摘要变化时更新观测消息时间，不因菜单重绘更新时间。最近访问记录限定当前窗口运行期间。每条显示：
1. 标题、本地／远程设备图标、相对时间；工作中用原生 loading 替代时间。
2. 最多两行省略的 AI 回答摘要。
3. 所属 Project 图标和名称（若有），不合并分组。

时间使用原生 hover card 的 recencyAt，缺失时 updatedAt；每30秒刷新。工作状态读取原生 statusState.type=loading。缓存会话数据与原生导航回调，复用导航和已读更新，不缓存 DOM 行，不发送消息。

打开时临时启用 Activity 以取得完整列表，关闭或卸载时恢复原先模式。只读取原生数据，预览不标记已读。界面及无障碍文案适配中英文。

入口只显示任务图标，不显示数量。浮层打开时使用原生 --modal-backdrop-background 遮罩覆盖底层界面；遮罩位于浮层下方，点击关闭并返回入口焦点，卸载时移除。

标题固定、条目容器独立滚动；浮层底部保留3个 spacing 单位（12px）固定内边距，滚动时仍保留。

点击后先同步显示浮层与可用数据，首帧绘制后再切换原生 Activity 补全条目；关闭或卸载会取消尚未开始的切换。

消息刷新时保留列表滚动位置与条目键盘焦点。当前身份消失时清除选中状态，最近访问缓存按一小时过期。
