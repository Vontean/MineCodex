# 未读会话入口

仅在线程侧栏收起时，在原生侧栏开关和 New chat 之间显示铃铛。复用原生 Activity 铃铛 SVG 与标题栏按钮属性；蓝点从侧栏开关移到铃铛，不改变原生未读状态。

悬停 120ms 打开，离开入口与面板 180ms 后关闭，允许经过两者之间的间隔。点击和键盘也可打开，Escape 关闭并返回焦点。展开侧栏时移除额外入口。

浮层复用原生 dropdown 背景、border、radius-2xl、shadow-xl-spread、text-sm 字体。宽 320px（视口不足时缩小），最大高 480px；每条会话独立展示三部分：标题、原生设备图标与相对时间；最多两行省略的 AI 回答摘要；该会话所属 Project 的图标及名称（若有）。条目使用原生文字、hover、圆角 token。点击调用原生会话行，已读状态交由 Codex 管理。

只在浮层打开期间临时启用隐藏侧栏的 Activity 视图以获得原生未读行；关闭时恢复原先模式。展开侧栏、卸载时恢复所有临时属性。悬停浏览不会标记已读，不发送消息。界面标题、空状态和无障碍标签提供中英文。

浮层以主内容区域左上角为锚点，距导航栏右缘16px、标题栏底缘16px。侧栏开关使用当前 Codex 原生 sidebar-hidden-light 的完整16/20px SVG，不裁掉通知图标的一部分。Project 信息在每个条目底部显示，不再合并分组；无项目的会话省略该部分。相对时间采用与原生 hover card 相同的 recencyAt（缺失时 updatedAt），打开时每30秒刷新；不将读取或打开面板的时间当作完成时间。

列表范围对齐原生 Priority：完成未读与工作中会话。工作状态读取原生 statusState.type=loading，右侧时间替换为原生旋转指示器；结束后未读则保留并显示时间，已读则移出。标题及入口标签使用 Priority / 优先事项。

工作中会话优先于完成未读会话；两组内均保留原生顺序。悬浮热区及开关延迟保持现状。
