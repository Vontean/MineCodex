# 未读会话入口

仅在线程侧栏收起时，在原生侧栏开关和 New chat 之间显示铃铛。复用原生 Activity 铃铛 SVG 与标题栏按钮属性；蓝点从侧栏开关移到铃铛，不改变原生未读状态。

悬停 120ms 打开，离开入口与面板 180ms 后关闭，允许经过两者之间的间隔。点击和键盘也可打开，Escape 关闭并返回焦点。展开侧栏时移除额外入口。

浮层复用原生 dropdown 背景、border、radius-2xl、shadow-xl-spread、text-sm 字体。宽 360px（视口不足时缩小），最大高 480px；列表使用原生 Activity 未读会话行的内容与样式，保留标题、项目、摘要，去掉嵌套操作按钮。点击调用原生会话行，已读状态交由 Codex 管理。

只在浮层打开期间临时启用隐藏侧栏的 Activity 视图以获得原生未读行；关闭时恢复原先模式。展开侧栏、卸载时恢复所有临时属性。悬停浏览不会标记已读，不发送消息。界面标题、空状态和无障碍标签提供中英文。

浮层以主内容区域左上角为锚点，距导航栏右缘16px、标题栏底缘16px。侧栏开关使用当前 Codex 原生 sidebar-hidden-light 的完整16/20px SVG，不裁掉通知图标的一部分。Project 按项目ID分组，上方显示原生项目图标与名称，去除会话标题后的项目后缀；无项目的会话不增加虚构项目标题。
