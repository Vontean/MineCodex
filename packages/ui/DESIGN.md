# UI 组件接入约定

视觉品味、组件分支与原生交互维护在根 [DESIGN.md](../../DESIGN.md)，组织和安装方式见 [本级 ARCHITECTURE](ARCHITECTURE.md)。本文件只记录调用方容易误用的组合与恢复契约。

## 内容与能力

page-script 通过 `config.ui` 组合通用组件，通过 `config.resources` 接收功能资源。选择材质时显式给出组件类型与所需分支；方法和选项查询当前安装器与组件源码，不在此维护另一份 API 清单。

Dialog 的标题、关闭和动作区属于共享结构，宽高、表单内容和业务回调属于功能。组件提供通用焦点机制；使用原生 dialog 时沿用其生命周期，功能提供恢复焦点目标，避免两套 Escape 或焦点圈定同时生效。

## 页面与主动导航

无专属二级导航的注入页面使用 `page(node, { sidebar:"none" })`。移除内容前调用 `releasePage(node)`；用户正在主动选择原生导航时传 `{ restoreNavigation:false }`，避免恢复动作覆盖新目的地。

`onNavigate` 只在原生路由提交后退出；悬浮侧栏和加载中的通知不表示用户已经离开。Adapter 通知前释放路由订阅并放弃旧位置恢复，功能回调清理自身内容与状态。`sidebar:"inherit"` 保留其接入语义，不因添加 none 分支而自动改变其他调用方。

当前 none Adapter 借用原生 `/projects` 页面壳，属于 Codex 26.930.21537 的版本适配，功能不把该路径当业务路由。官方 MCP 页面使用宿主壳，不调用此注入恢复过程。

## 资源与状态恢复

NavigationRail 按当前 committed 原生状态恢复，原生节点重建后保持单一展示图标；官方 MCP 导航只更新所属 SVG mask 资源，恢复时保留原生后来写入的状态。具体资源契约由 native Adapter 维护。

Tooltip 声明与清理由共享组件维护。专有内容使用共享材质，功能维护其内容、定位和订阅；原生 Tooltip 不归共享观察器接管。

## 验证

验证可注入性、内容与回调、挂载和焦点、节点复用与资源清理。选择原生分支或改变导航时，按根 DESIGN 的交互标准做隔离验收；纯文件迁移核对依赖、序列化、包名单和既有行为。CSS 常量不逐项镜像成实现测试。
